# Screenshots

Captures taken while porting the design, kept because a rewrite is worth being able to
check against what it replaced.

- **`legacy/`** — the original Laravel 7 + Vue 2 app, captured from the running site at
  <https://phive.ivqonsanada.com>. The code is on the
  [`legacy`](https://github.com/ivqonsanada/phive/tree/legacy) branch.
- **`rewrite/`** — the same screens in the Laravel 13 + Next.js 16 app.

Both sets are desktop, 1425px wide, so a pair can be compared directly.

Only signed-out screens are here. Everything behind a login — inbox, party, project box,
settings, shortlist, review — has no legacy counterpart to capture, because that would
need an account on the old site.
